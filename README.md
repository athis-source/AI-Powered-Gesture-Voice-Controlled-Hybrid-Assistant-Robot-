# AI-Powered Gesture & Voice Controlled Assistant Robot 🤖

## Problem Statement
Enable hands-free interaction for differently-abled individuals
using gesture and voice commands.

## Technologies Used
- Python
- MediaPipe (Gesture Recognition)
- Vosk (Offline Voice Recognition)
- Arduino (Motor Control)
- Bluetooth Communication

## System Workflow
1. Webcam captures hand gestures
2. MediaPipe detects gestures
3. Voice commands processed using Vosk
4. Commands sent to Arduino via Bluetooth
5. Robot executes movement/actions

## Features
- Gesture-based navigation
- Voice-controlled commands
- Hybrid joystick fallback

## Outcome
A functional prototype demonstrating multimodal human–computer interaction.
